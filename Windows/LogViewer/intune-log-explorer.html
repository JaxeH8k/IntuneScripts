Intune Log Explorer

MDM diagnostic event channels

Read the Intune client logs on this device

This page works straight off disk — no web server, no install, no internet. A browser can’t open C:\Windows\System32\winevt\Logs\*.evtx by itself (those files are ACL-restricted and JS has no filesystem access), so step 1 exports the three MDM channels to a small JSON file that this page then reads. No administrator rights required.

1

Export the event channels

Copy this into Windows PowerShell and press Enter. It reads …Diagnostics-Provider/Admin, /Operational and /Sync and writes intune-logs.json to your Desktop. Edit the variables at the top to change the window or output folder.
